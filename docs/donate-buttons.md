# Donate buttons

- **New blog posts** end with a Donate button that opens the Givebutter form. Delete it if a post doesn't need it.
- **Other donate blocks:** in the block inserter, open `Patterns -> Grace Helping Hands`.
- **Show a different form:** set any button's link to `#givebutter-` plus the campaign ID, for example `#givebutter-5XT0XG`.
