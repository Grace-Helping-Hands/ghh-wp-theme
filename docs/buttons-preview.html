Button styles

Open this file in a browser from the repo: it loads the theme's real CSS from assets/css. Hover to see the hover state, Tab to see keyboard focus, and click a class name to copy it.

How to use them

In the editor (Button block)

  1. Add a Buttons block and select the button.
  2. In the sidebar, open Advanced.
  3. In Additional CSS class(es), type the classes, for example btn btn-primary.
  4. Leave the block's own color settings empty; they would override these.

In theme templates

<a class="btn btn-primary btn-lg" href="/donate/">Donate</a>
